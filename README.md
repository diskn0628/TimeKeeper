Timekeeper (iPhone / PC / PWA)
放送現場のタイムキーパー（TK）やイベント進行ディレクター向けに設計された、高精度・完全ローカル動作の時間管理Webアプリケーションです。
🚀 主な特徴
￼ 完全オフライン動作: 電波の届かない副調整室（サブ）や地下スタジオでも単体で確実に稼働。
￼ TM・CDリアルタイム連動: カウントダウン中にタイマーの残り時間を差し引いた「ケツ合わせ」を瞬時に確認可能。
📱 各タブの使い方
1. ⏰ CD（カウントダウン）
目標時刻（例: ⁠143000⁠ → 14:30:00）までの残り時間を計測します。
￼ 追加: 数字入力（4〜6桁）またはプリセットタップで追加。
￼ 👉 右ドラッグ / 右スワイプ: TM連動差分表示（現在稼働中のタイマー時間を差し引いた、タイマー終了時点でのCD残り時間をリアルタイム表示）。
￼ 👈 左ドラッグ / 左スワイプ: ラベル編集 / 削除。
￼ ▲▼ または 長押しドラッグ: リストの並び替え。
￼ ダブルタップ: フローティング小窓化。
2. ⏳ TM（タイマー）
指定時間（例: ⁠0300⁠ → 3分）のカウントダウンを行います。複数タイマーの同時稼働に対応。
￼ 追加: プリセットタップ、または数字を入力して「＋」。
￼ 👉 右ドラッグ / 右スワイプ: スタートからの「経過時間」を表示。
￼ 👈 左ドラッグ / 左スワイプ: ラベル編集 / 削除。
￼ ↺ ボタン: リセット / 初期値に戻す。
3. ⏱ SW（ストップウォッチ）
ミリ秒精度の計測と、2系統のラップ記録が可能です。
￼ LAP 1: 「分割（スプリット）」または「差分（1→2）」を記録（右上のボタンでモード切替）。最速/最遅ラップを自動ハイライト。
￼ LAP 2: 累積ラップ差を青色で独立記録。
￼ ダブルタップ: 時計部分を小窓化。
4. 🧮 CALC（時間電卓）
時間専用の加減算電卓です。キーボード入力にも対応しています。
￼ 入力例: ⁠143000⁠ (14:30:00) ＋ ⁠5m⁠ (5分) − ⁠30s⁠ (30秒)
￼ 📋 コピー: 計算結果の6桁数字をコピーし、CDやTMの入力欄へ即座に連携。
💡 共通機能・ショートカット
￼ 現在時刻の調整（ヘッダークロック長押し）:
右上の時計を長押しすると、手動で基準時刻をシフト・オフセット設定できます。
￼ 全画面横モード（ヘッダークロックをダブルタップ）:
画面全体を大型デジタル時計＋選択中タイマーの特大表示に切り替えます。
￼ フローティング小窓（アイテムをダブルタップ）:
￼ ドラッグで画面内の好きな位置へ移動。
￼ 右下のつまみでウィンドウサイズを変更。
￼ 中央バーを上下にドラッグしてラベルと数字の比率を調整。
￼ ↗ ボタン: 外部モニター用の別ウィンドウをワンクリックでポップアップ表示。
￼ −2秒などの早め設定（Quick Offset）:
「−2秒」ボタンをタップでON/OFF、長押しで早める秒数を自由に変更可能。
