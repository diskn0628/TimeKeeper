# Timekeeper iPhone 取扱説明書（クイックガイド）

本アプリは、テレビ放送やイベント現場向けの高精度タイマーWebアプリです。

### 🌟 現場で選ばれる2大メリット
- **オフライン完全対応**: ネットがある場所で一度開いておけば、電波のない地下や中継現場でも動作します。
- **完全無音設計**: タイマー終了時もアラーム音やビープ音は一切鳴りません。マイクを生かした本番中でも安心です。

---

## 1. ヘッダークロック（画面右上の時計）

- **時計を長押し（0.6秒）する**
  👉 **時刻を手動変更できる**（仮想時刻オフセット）。アプリ全体の基準時刻が連動します。「RST」で元に戻せます。
- **時計をダブルタップする**
  👉 **画面全体が超大型時計になる**（ランドスケープ表示）。子画面を出していればタイマーと時計を上下に同時大型表示できます。もう一度ダブルタップで復帰。

---

## 2. CDモード（指定時刻カウントダウン）

指定した時刻（番組終了・コーナー締めなど）までの残り時間を管理します。

- **時刻を入力して「＋」を押す**
  👉 **指定時刻までのカウントダウンを追加できる**（例: `1430` → 14:30:00 まで）。
- **「−X秒」ボタンをタップする**
  👉 **指定秒数早くタイムアップできる**（スティール機能・早め設定）。長押しで秒数を変更可能。
- **カードを長押し（0.4秒）して上下に動かす**
  👉 **並び順を自由にドラッグ＆ドロップで入れ替えられる**（▲▼ボタンでも可）。
- **カードを左スワイプする**
  👉 **ラベルの変更や削除ができる**。
- **カードを右スワイプする**
  👉 **TMモードで動いているタイマーとの差分（余力 / 不足）を即座に確認できる**。
- **カードをダブルタップする**
  👉 **フローティング子画面（画面内を自由に動かせるミニ画面）を出せる**。
- **プリセット欄の「＋」を押す**
  👉 **よく使う時刻をプリセットとして登録できる**（時刻とプリセット名称を入力。定型文候補もタップで名称に使える）。
- **プリセットを長押しする**
  👉 **登録済みプリセットの時刻・名称の編集や削除ができる**。

---

## 3. TMモード（汎用タイマー）

VTR尺やトーク時間などをカウントダウン計測します。

- **プリセットボタンを押す / 数値を入れて「＋」を押す**
  👉 **タイマーを追加できる**（例: `0300` → 3分、`45s` → 45秒）。
- **タイマーの「REF」ボタンを押す**
  👉 **そのタイマーが「基準」になり、他の全タイマーとの残り時間の差分（残余/不足）がリアルタイム表示される**。
- **カードを右スワイプする**
  👉 **スタートからの「経過時間」を確認できる**。
- **カードを左スワイプする**
  👉 **ラベル編集や削除ができる**。
- **カードをダブルタップする**
  👉 **フローティング子画面を出せる**。
- **プリセット欄の「＋」を押す**
  👉 **よく使う設定時間をプリセットとして登録できる**（設定時間とプリセット名称を入力。定型文候補もタップで名称に使える）。
- **プリセットを長押しする**
  👉 **登録済みプリセットの設定時間・名称の編集や削除ができる**。

---

## 4. SWモード（ストップウォッチ）

1/100秒単位で高精度計測します。

- **「LAP1」を押す**
  👉 **スプリット / 区間ラップを記録できる**（上のスイッチで「通算」と「区間差分」を切替可。最速・最遅を自動判定）。
- **「LAP2」を押す**
  👉 **もう1系統の独立したラップ系列を並行して記録できる**。
- **タイム表示部をダブルタップする**
  👉 **ストップウォッチのフローティング子画面を出せる**。

---

## 5. CALCモード（時間計算電卓）

放送尺や時間枠の計算を行います。

- **数字と「＋」「−」「s（秒）」「m（分）」を押す**
  👉 **時・分・秒の計算が直感的にできる**（例: `90` は自動で 1分30秒 に変換）。
- **「📋 コピー」を押す**
  👉 **計算結果をコピーし、CD/TM/SWタブを開くと入力欄に自動で反映される**。

---

## 6. フローティング子画面 ＆ 外部出力

- **子画面をドラッグする**
  👉 **好きな位置へ自由に移動できる**。
- **子画面の右下角をドラッグする**
  👉 **画面サイズを拡大・縮小できる**。
- **子画面の中央のバーを上下にドラッグする**
  👉 **ラベルと数字の高さバランス（比率）を調整できる**。
- **子画面をダブルタップする**
  👉 **「全画面表示（⛶）」や「外部モニター出力（↗）」などのボタンを表示できる**。
  - **「⛶（全画面）」を押す**: 画面いっぱいに超特大フォントで表示。
  - **「↗（外部出力）」を押す**: ブラウザの別ウィンドウが開き、外部ディスプレイや返しモニター用としてタイマーを独立送出できる。
